# ☕ Projetos Java

Bem-vindo(a) ao meu repositório de **Projetos Java**!

Este espaço foi criado com o objetivo de armazenar, organizar e documentar meus projetos práticos desenvolvidos utilizando a linguagem Java.

Aqui compartilho minha jornada de aprendizado em programação, colocando em prática conceitos fundamentais e avançados por meio de exercícios, desafios e projetos pessoais.

## 🎯 Objetivos

- Desenvolver e aprimorar minhas habilidades em Java.
- Fortalecer a lógica de programação.
- Aplicar os conceitos de Programação Orientada a Objetos (POO).
- Trabalhar com estruturas de dados e Collections.
- Aprender a desenvolver aplicações integradas com bancos de dados.
- Desenvolver APIs e aplicações Back-end.
- Aplicar boas práticas de programação e organização de código.

## 🛠️ Tecnologias e ferramentas

- **Java** – Linguagem principal utilizada nos projetos.
- **MySQL** – Gerenciamento e integração com bancos de dados.
- **JDBC** – Conexão entre aplicações Java e bancos de dados.
- **IntelliJ IDEA** – Ambiente de desenvolvimento.
- **Git e GitHub** – Versionamento e armazenamento dos projetos.
- **Spring Boot** – Desenvolvimento de aplicações e APIs REST.

## 📚 Conteúdos praticados

- Lógica de programação.
- Variáveis e tipos de dados.
- Estruturas condicionais.
- Estruturas de repetição.
- Arrays e Matrizes.
- Métodos e funções.
- Programação Orientada a Objetos (POO).
- Encapsulamento, Herança e Polimorfismo.
- Collections e Generics.
- Tratamento de exceções.
- Manipulação de arquivos.
- Integração com bancos de dados.
- Desenvolvimento de APIs REST.

## 🚀 Evolução contínua

Este repositório será atualizado constantemente com novos projetos, exercícios e desafios práticos, acompanhando minha evolução na programação Java e no desenvolvimento de software.
